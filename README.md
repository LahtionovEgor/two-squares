# Про 2 квадрата — игра в Telegram

Казуальная игра по «Супрематическому сказу про 2 квадрата в 6-ти постройках»
Эля Лисицкого (1922). Игрок ведёт красный или чёрный квадрат по миру
в стиле русского авангарда.

- Играть: [@two_squares_bot](https://t.me/two_squares_bot)
- Сайт игры (GitHub Pages): https://lahtionovegor.github.io/two-squares/

Сейчас это каркас (этап 3): меню, пустой мир и экран «Проверка Telegram».

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | меню и экраны, связь с Telegram, сохранение |
| `game.js` | движок: холст, цикл кадров, рисование |
| `world.js` | карта мира и зоны |
| `fonts/` | шрифты DejaVu Sans Bold и Manrope с лицензиями |

Чистый HTML/CSS/JS без сборки. Всё рисуется кодом на canvas, картинок нет.

## Как обновлять

1. Правки выкладываются в ветку `main`.
2. GitHub Pages обновляет сайт за 1–2 минуты.
3. В Telegram полностью закрыть Mini App и открыть снова.
   Номер сборки виден на экране «Проверка Telegram».

При изменении `world.js` или `game.js` в `index.html` увеличивается номер `?v=N`,
иначе Telegram может показать старую версию из кэша.
